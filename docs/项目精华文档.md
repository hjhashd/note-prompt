# 🚀 Note Prompt 系统 - 精华文档

## 📋 项目概述

**note-prompt** 是一个智能提示词管理和编辑系统，提供现代化的前端界面，支持提示词的创建、编辑、管理和AI辅助功能。

---

## 🎯 核心功能

### 🔧 主要模块
- **提示词管理**: 创建、编辑、删除、重命名提示词
- **AI 辅助编辑**: 智能内容生成、优化建议
- **标签系统**: 提示词分类和标签管理
- **用户界面**: 现代化的编辑器和交互界面

### 🌐 服务架构
- **前端**: Vue.js + Vite
- **后端集成**: Python API (12543) + Java API (12544)
- **部署方式**: Docker 容器化

## ⚠️ 重要注意事项

### 🔐 安全配置
- API 地址需要根据实际部署环境调整
- 生产环境端口需要防火墙配置
- 确保后端服务正常运行

### 🌐 网络配置
- 前端通过 Nginx 反向代理访问后端
- 容器间通信使用服务名或宿主机 IP
- 确保网络可达性和端口开放

### 🗄️ 数据存储
- 提示词数据存储在后端数据库
- 前端主要负责展示和交互
- 建议定期备份重要数据

## 🆘 故障排除

### 🔧 常见问题

1. **容器启动失败**
   ```bash
   # 检查 Docker 状态
   docker info

   # 查看详细错误日志
   docker-compose -p note-prompt-prod logs
   ```

2. **API 连接失败**
   - 检查后端服务是否正常运行
   - 验证 API 地址配置是否正确
   - 确认网络连接和端口开放

3. **端口占用**
   ```bash
   # 检查端口占用
   lsof -i :10086
   lsof -i :5173

   # 强制释放端口
   kill -9 <PID>
   ```

4. **权限问题**
   ```bash
   # 部署脚本需要 cqj 用户权限
   su - cqj
   ./deploy.sh
   ```
